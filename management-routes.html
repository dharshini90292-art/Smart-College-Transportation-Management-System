Section E — Attendance-Based Route Optimization Breakdown ({{selectedDate}})

Daily attendance status determines active stops. A stop is skipped ONLY when all assigned students are confirmed Absent for the selected date. If at least 1 student is Present, or if attendance is unconfirmed, the stop remains active for safety.

{{attendanceBreakdownRows}}
Stop Name Assigned Present Absent Unmarked Status Optimization Reason
Rule 1 • Active Pickup

If at least one assigned student is marked Present, the stop is retained on the active pickup route.

Rule 2 • Skipped Stop

A stop is bypassed ONLY when 100% of assigned students have confirmed Absent records for that date.

Rule 3 • Safety Fallback

If attendance is missing or unknown for any student, the stop is NEVER skipped.

Rule 4 • Non-Destructive

Bypassing a stop for a day never deletes the stop record or changes permanent assignments.
